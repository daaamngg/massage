# Мастерская массажа и косметологии Натальи Хасаншиной

Лендинг премиального массажного салона в Самаре.
Next.js (App Router) + TypeScript + Tailwind CSS.

## Локальный запуск

```bash
npm install
npm run dev          # разработка, http://localhost:5187
```

```bash
npm run build        # production-сборка
npm run start:local  # запуск сборки локально на 5187
```

## Переменные окружения

Создать `.env.local` (в репозиторий он **не** попадает):

```
TELEGRAM_BOT_TOKEN=<токен бота от @BotFather>
TELEGRAM_CHAT_ID=<id получателя, через запятую можно несколько>

# Необязательно — заявки ещё и в ВК, сообщением от сообщества:
VK_GROUP_TOKEN=<ключ доступа сообщества с правом на сообщения>
VK_NOTIFY_USER_IDS=<id страниц ВК через запятую>
```

Заявки с формы уходят через серверный маршрут `app/api/booking` — в Telegram
и, если заданы переменные ВК, в сообщения ВК. Заявка считается принятой,
если дошла хотя бы до одного получателя. Токены читаются только на сервере
и в браузер не попадают.

**Важно:** каждый получатель должен один раз нажать «Старт» у бота —
иначе Telegram не разрешит боту ему написать.

### Как подключить ВК

1. Сообщество → **Управление → Сообщения** — сообщения сообщества включены.
2. **Управление → Работа с API → Ключи доступа → Создать ключ**, отметить
   доступ к сообщениям сообщества. Ключ — в `VK_GROUP_TOKEN`.
3. Каждый получатель **один раз пишет сообществу** что угодно — без этого
   ВК не даст сообществу написать первым.
4. id получателя — число из адреса страницы: у `vk.com/id123456` это `123456`.

## Деплой (Timeweb Cloud → App Platform)

1. Framework: **Next.js**
2. Build command: `npm run build`
3. Start command: `npm run start` (платформа сама передаёт `PORT`)
4. В настройках приложения задать переменные окружения из блока выше
5. Привязать домен, SSL выдаётся автоматически
