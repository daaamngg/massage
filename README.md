# Мастерская массажа и косметологии Натальи Хасаншиной

Лендинг премиального массажного салона в Самаре.
Next.js (App Router) + TypeScript + Tailwind CSS.

## Локальный запуск

```bash
npm install
npm run dev          # разработка, http://localhost:5187
```

```bash
npm run build        # production-сборка
npm run start:local  # запуск сборки локально на 5187
```

## Переменные окружения

Создать `.env.local` (в репозиторий он **не** попадает):

```
TELEGRAM_BOT_TOKEN=<токен бота от @BotFather>
TELEGRAM_CHAT_ID=<id получателя, через запятую можно несколько>
```

Заявки с формы уходят в Telegram через серверный маршрут `app/api/booking`.
Токен читается только на сервере и в браузер не попадает.

**Важно:** каждый получатель должен один раз нажать «Старт» у бота —
иначе Telegram не разрешит боту ему написать.

## Деплой (Timeweb Cloud → App Platform)

1. Framework: **Next.js**
2. Build command: `npm run build`
3. Start command: `npm run start` (платформа сама передаёт `PORT`)
4. В настройках приложения задать переменные окружения из блока выше
5. Привязать домен, SSL выдаётся автоматически
